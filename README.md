# Predictive Analytics of Reliance Industries Stock Prices



## Project Overview


Developed a Predictive Analytics Dashboard to analyze and forecast Reliance Industries stock prices using historical market data. The project leverages Linear Regression to predict stock price movements and visualize trends, trading activity, and model performance through an interactive Power BI dashboard.



## Tools Used


- Python

- Pandas

- NumPy

- Scikit-learn

- Matplotlib

- Power BI



## Key Features

- Historical stock price analysis

- Data cleaning and preprocessing

- Linear Regression-based stock price prediction

- Actual vs Predicted price comparison

- Trading volume analysis

- Interactive dashboard with date filters

- KPI tracking and trend visualization

## Key Insights

### Stock Price Performance

- Reliance Industries stock exhibited a consistent long-term upward trend during the analysis period.

- The stock price remained relatively stable with periodic fluctuations driven by market conditions.


### Trading Activity

- Significant spikes in trading volume indicate periods of increased market participation and investor activity.

- High-volume trading sessions often coincided with notable price movements.


### Predictive Model Performance

- The Linear Regression model successfully captured the overall stock price trend.

- Predicted prices closely followed actual market prices, demonstrating the model's effectiveness for trend forecasting.

- The model provided reliable directional insights for understanding future price movement patterns.


### Trend Analysis

- Historical analysis revealed steady growth with occasional corrections.

- Long-term market sentiment remained positive throughout the observed period.


## Business Value

- Supports data-driven investment analysis and decision-making.

- Helps identify market trends and potential future price movements.

- Demonstrates the application of predictive analytics in financial markets.

- Provides an interactive framework for monitoring stock performance and forecasting outcomes.
